This is where I post short updates that don't belong inside individual repo wikis or buried release threads.

**What you'll find here:**

- Release announcements — starting with [SlothClash](https://github.com/Nemu-x/SlothClash) and [ClashFest](https://github.com/Nemu-x/ClashFest), with more projects over time
- Dev notes on what changed and why
- Occasional diary entries when something is worth explaining

**What you won't find:**

- Full changelogs — those stay on GitHub Releases
- Docs — those live in each project's README

Posts are intentionally short. If you follow anything in the Nemux ecosystem, this is the fastest way to see what shipped.
