[SlothClash v0.6.0](https://github.com/Nemu-x/SlothClash/releases/tag/v0.6.0) is the big polish release — security, signed self-updates, and a UI overhaul.

## Highlights

- **Signed, fail-closed in-app updates** — releases verified with minisign (ed25519) before anything launches; unsigned or tampered builds are refused
- **Update UX** — download progress, in-app changelog, restart-to-apply flow, automatic updates toggle
- **CI security gating** — `govulncheck` and `pnpm audit --prod` block on known vulnerabilities
- **Mihomo core pinned to v1.19.26** — reproducible builds, no more `latest` at compile time
- **Import local configs & share links** — `config.yaml`, `vless://`, `vmess://`, `ss://`, and more
- **Visual overhaul** — design-token system, milky-coffee light theme, Proxies accordion, reworked Rules modal

## Fixes worth noting

- TUN no longer breaks the first connect after an in-app update
- Windows installer shows progress during VC++ runtime install
