[🦥 ClashFest v1.4.1](https://github.com/Nemu-x/ClashFest/releases/tag/v1.4.1) is out.

The APK is half the size again.

## 🛠️ Fix — APK size

- **Back to ~50 MB.** 1.4.0 stored the core library uncompressed inside the APK, which doubled every download (arm64 48 → 101 MB). 1.4.1 compresses it again: arm64 is ~48 MB, like 1.3.0. Nothing else changed.

Everything new in 1.4.0 — Desync, mihomo 1.19.34, Xray 26.11.9 compatibility — is in the [1.4.0 notes](https://github.com/Nemu-x/ClashFest/releases/tag/v1.4.0).

---

🧪 Tested on-device: Motorola razr 40 (Android 15) — the release APK installs, the core starts, the VPN connects.
